## 项目简介

单一来源的数据只能描述某一方面特征，难以回答空气质量与产业结构、道路分布、气象条件之间的关系。本项目以江苏省 13 个地级市为研究区域，将五类异构数据经过清洗、规范化与跨源（实体 / 时间 / 空间）关联后，围绕三个层次的问题展开分析：

1. **城市年度尺度**：产业结构、经济发展与生态条件如何与城市年均 PM2.5 水平关联；
2. **监测站点尺度**：站点周边道路环境（缓冲区道路长度、最近道路距离）与六种污染物浓度是否存在稳定关联；
3. **城市日度尺度**：融合历史污染、气象、土地覆盖与城市经济特征，能否改善高污染日（日均 PM2.5 > 75 μg/m³）识别。

整体流程为：**数据获取 → 清洗与质量检查 → 跨源关联 → 分析建模 → 可视化与结果核验**，并保留原始（Raw）、清洗（Cleaned）、融合（Integrated）三个数据层次。

## 研究问题

### 问题一：产业结构与生态条件和城市 PM2.5 的关联

- **样本**：江苏省 13 市，2014—2024 年，按城市—年份内连接并筛选关键字段完整记录后共 **143 个观测**。
- **变量**：PM2.5 年均浓度（两套口径）、第二产业占比、人均 GDP 对数（ln_gdp）、建成区绿化覆盖率、人均公园绿地面积。
- **方法**：描述性统计（热力图、多年均值对比、经济—生态四象限散点）、合并 OLS 回归、K-Means 聚类（K=3，聚类特征不含 PM2.5）、土地利用一阶差分探索。

### 问题二：道路环境与监测站点空气质量的关联

- **样本**：2026-01-01 至 2026-10-31，筛选后 **81 个监测站点**（覆盖 13 个地级市）。
- **污染物**：PM2.5、PM10、SO₂、NO₂、O₃、CO。
- **道路变量**：500m / 1000m / 2000m 缓冲区内高速/快速路、主干道、次干/支路长度，以及最近道路距离、最近主干道距离（共 11 项）。
- **方法**：Spearman 秩相关（BH-FDR 校正）、城市固定效应多元回归（6 污染物 × 3 缓冲区 = 18 个模型）、高峰—夜间差值分析、K-Means 聚类（污染画像 / 道路环境 / NO₂ 日变化，PCA + 轮廓系数选 K）、MAD 稳健 z 分数与 kNN 多变量异常检测、Apriori 关联规则挖掘。

### 问题三：多源特征融合与高污染日识别

- **标签**：日均 PM2.5 > 75 μg/m³ 记为高污染日（1），否则为 0。
- **样本**：清洗与时空对齐后共 **37,505 条**城市—日记录；按时间划分，2018—2021 为训练期（18,902 条），2022 年及以后为测试期（18,603 条）。
- **递进模型**（随机森林，`class_weight='balanced'`，核心指标 F1）：
  - 模型 A（基准）：历史空气质量 + 气象特征；
  - 模型 B（融合土地）：A + 土地覆盖特征；
  - 模型 C（多源融合）：B + 城市经济特征。

## 分析方法

- **统计建模**：合并 OLS 回归（问题一）、城市固定效应对数回归与联合 F 检验（问题二）、一阶差分回归（探索性）。
- **数据挖掘**：K-Means 聚类（k-means++ 初始化、z 分数标准化、轮廓系数选 K、PCA 降维）、MAD 稳健异常检测、kNN 多变量离群检测、Apriori 频繁项集与关联规则（支持度 / 置信度 / 提升度）。
- **机器学习分类**：随机森林三模型递进对比，F1 为核心评价指标，特征重要性辅助解释。
- **空间处理**：缓冲区相交、最近距离计算、行政边界掩膜与分区统计（rasterio / geopandas）。
- **多重检验**：Spearman 相关经 Benjamini–Hochberg FDR 校正，以校正后 q < 0.05 为显著性标准。

## 主要结果

**问题一（城市年度）**

- 第二产业占比系数显著为正（+0.855，p < 0.001）：控制其他变量后，二产占比每高 1 个百分点，PM2.5 平均约高 0.86 μg/m³；
- 人均 GDP 对数系数显著为负（−19.07，p < 0.001），人均公园绿地面积系数显著为负（−1.030，p = 0.006）；建成区绿化覆盖率系数为正但不显著（p = 0.117）；
- K-Means 将 13 市分为三类（通扬镇生态良好型 / 低二产低经济型 / 高人均 GDP 发达型），提示单纯低二产占比不必然带来更优空气质量。

**问题二（监测站点）**

- 81 站样本中，六种污染物与 11 项道路变量的相关整体较弱；原始 p < 0.05 的项经 BH-FDR 校正后 q > 0.05，仅作探索性弱信号；
- 控制城市差异后，三个缓冲区内道路长度系数均未达到 p < 0.05，当前样本与模型设置下**尚未稳定识别出**道路长度与污染物研究期均值的额外关联（不等于道路没有影响）；
- 聚类与关联规则呈现区域共现：苏南站点 NO₂、CO 相对较高，徐州/宿迁/连云港部分站点颗粒物相对较高；异常站点集中于徐州、宿迁、连云港。

**问题三（高污染日识别）**

| 模型 | 特征组合 | 测试集 F1 |
|---|---|---|
| A（基准） | 历史空气质量 + 气象 | 0.4844 |
| B（融合土地） | A + 土地覆盖 | **0.4963** |
| C（多源融合） | B + 城市经济 | 0.4920 |

- 加入土地覆盖后 F1 提升 0.0119；进一步加入月度经济特征未带来额外提升（时间尺度错配可能是原因之一）；
- 特征重要性：昨日 PM2.5 最高、昨日 PM10 靠前，风速/温度/降水等气象特征次之；
- 时间上 PM2.5 月均呈"U 型"季节变化（冬季高、夏季低）；空间上徐州、宿迁多年均值较高，盐城、南通较低。

## 使用说明

1. **获取数据**：按"数据来源"表记录的方式下载原始数据至 `data/raw/`（大文件建议通过说明文档记录来源与获取时间，不直接提交 Git）。
2. **顺序执行清洗脚本**：先运行 `src/01`—`05` 的清洗与聚合模块，生成 `data/cleaned/`。
3. **跨源关联**：按研究问题建立城市—年份、站点、城市—日期三种关联单元，输出 `data/integrated/` 建模宽表。
4. **复现分析**：分别运行 `q1_industry_eco`、`q2_roads_sites`、`q3_haze_days` 模块，结果表与图表输出至 `figures/`。
5. **核验**：对照清洗质量报告、输出 CSV 与报告结果表逐项核对样本量、系数、p 值与图表数值。

## 结果与解释说明

- 本项目回归、相关与聚类结果均为**统计关联 / 样本模式**，特征重要性反映模型对变量的利用程度，**不直接等同于因果作用或污染形成机制**。
- 道路长度仅为路网密度代理变量，不等同于实际车流量、拥堵或排放强度；未通过 FDR 校正的相关项不作为统计显著结论。
- 问题三 F1 提升幅度较小，其稳定性需跨时段进一步验证；模型按时间划分训练/测试集，避免随机划分造成时期交叉。
- 各结论应结合对应数据范围与处理规则理解，在其他年份、地区或空间尺度的适用性仍需检验。

## 局限与展望

- **数据尺度**：不同来源统计年份、时间频率与空间范围不一致；静态土地覆盖难以刻画逐年变化，月度经济指标与日度污染时间尺度错配。
- **变量覆盖**：问题二未纳入实际交通流量、ETC/公交等活动信息；部分字段存在缺失，缺失处理方式可能影响有效样本。
- **方法扩展**：后续可统一数据口径、补充交通活动信息、比较不同缺失处理方案，并增加跨时段验证与空间模型。
